Chat like a real hacker.

Y is a decentralized, peer-to-peer communication protocol built in Rust. Leveraging Tor and DHT for a chat experience where no central authority exists.

Enter the Network Explore Tech

Hardened Foundations

Built with a focus on memory safety, cryptographic rigor, and absolute privacy.

Tor Integrated

Every connection is routed through the Tor network, masking your IP address and providing native anonymity for every peer.

DHT Networking

Distributed Hash Tables allow peers to find each other without relying on a central directory or single point of failure.

X25519 Crypto

State-of-the-art Elliptic Curve Diffie-Hellman for key exchange and Ed25519 for identity signatures.

Rust Core

High-performance asynchronous I/O with zero-cost abstractions, ensuring the software is fast and memory-safe.

TUI Interface

A lightweight terminal user interface that stays out of your way and works across any SSH session.

The Mediator

Just a regular peer that stays online 24/7 to help new users find the network. No special privileges, no control, just a lighthouse.

Global Timeline

Connect to a mediator to access the global feed — unfiltered posts from across the network. Share ideas, discuss freely, no moderation from above.

User Discovery

Search and find other users by alias — only available when connected to a mediator. Direct peer connections don't expose the network directory.

Communities (Experimental)

Create open or private groups with owner-controlled membership. Self-governed, no central moderation. Still evolving — expect rough edges.

The Trustless Architecture

1

Identity Generation: Users generate an Ed25519 keypair locally. Your public key is your identity; no email or phone required.

2

Connect to Peers: Either connect directly via a known .onion address, or use an optional Discovery Node (mediator) for instant DHT bootstrap.

3

Encrypted Tunnel: Peers establish an X25519 session key. All traffic is then wrapped in Tor layers for maximum privacy.

Quick Start

Choose your path to anonymity.

One-liner bash 
curl -sL https://raw.githubusercontent.com/elvisthebuilder/Y/main/install.sh | sh
From Source bash 
# Clone the repository
git clone https://github.com/elvisthebuilder/Y.git
cd Y

# Build the release version
cargo build --release

# Launch the TUI
./target/release/y

Make sure you have the Tor daemon running on your system before launching Y to enable network connectivity.
